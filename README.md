PP02 — Производственная практика (Системное администрирование)
Описание
Данный репозиторий содержит материалы производственной практики ПП.02 по направлению «Системное администрирование».
В ходе практики выполнялись задачи по администрированию ИТ-инфраструктуры пунктов выдачи заказов Ozon,
автоматизации работы системного администратора и обеспечению стабильной и безопасной работы оборудования ПВЗ.

Практика выполнялась в среде Windows с использованием PowerShell и средств администрирования ОС.

Скрипты администрирования PowerShell для ПВЗ Ozon:

Цель производственной практики:
Получение практических навыков системного администрирования распределённой сети ПВЗ,
автоматизация задач обслуживания терминалов и рабочих станций,
обеспечение безопасности данных клиентов Ozon,
повышение отказоустойчивости и надёжности работы ИТ-инфраструктуры пунктов выдачи.

Используемые технологии
ОС: Windows 10/11, Windows Server

Скриптинг: PowerShell 5.1 / 7

Моделирование: UML (PlantUML, Draw.io)

Базы данных: SQLite, PostgreSQL (скрипты обслуживания)

Версионный контроль: Git, GitHub

Мониторинг: WMI, CIM, Performance Counters
