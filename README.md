#  PP02 — Производственная практика (Системное администрирование)

## Описание

Данный репозиторий содержит материалы производственной практики ПП.02 по направлению «Системное администрирование».

В ходе практики выполнялись задачи по **администрированию ИТ-инфраструктуры пунктов выдачи заказов Ozon**, автоматизации работы системного администратора и обеспечению стабильной и безопасной работы оборудования ПВЗ.

Практика выполнялась в среде **Windows** с использованием **PowerShell** и средств администрирования ОС.

### `scripts/`
**Скрипты администрирования PowerShell для ПВЗ Ozon:**

| Файл | Назначение |
|------|------------|
| `backup_pvz_data.ps1` | Резервное копирование БД и конфигов ПВЗ |
| `restore_pvz_data.ps1` | Восстановление данных ПВЗ из бэкапа |
| `create_pvz_user.ps1` | Создание учётной записи сотрудника |
| `disable_pvz_user.ps1` | Блокировка уволенного сотрудника |
| `monitoring_pvz.ps1` | Мониторинг доступности терминалов |
| `disk_check_pvz.ps1` | Проверка свободного места на ТСД/ПК |
| `network_check_pvz.ps1` | Диагностика Ethernet/4G-модемов |
| `update_pvz_windows.ps1` | Централизованная установка обновлений |
| `cleanup_pvz_temp.ps1` | Очистка временных файлов и кэша |
| `antivirus_check_pvz.ps1` | Проверка статуса антивирусной защиты |
| `pvz_logs_analyzer.ps1` | Сбор и анализ системных журналов |
| `reboot_pvz_terminal.ps1` | Удалённая перезагрузка зависшего ТСД |
| `sync_offline_pvz.ps1` | Синхронизация ПВЗ с 4G-каналом |
| `pvz_inventory.ps1` | Инвентаризация оборудования ПВЗ |

## Цель работы

Получение практических навыков системного администрирования распределённой сети ПВЗ Ozon, автоматизация задач обслуживания терминалов, обеспечение безопасности данных клиентов, повышение отказоустойчивости ИТ-инфраструктуры пунктов выдачи.

---

## Используемые технологии

- **ОС:** Windows 10/11, Windows Server
- **Скриптинг:** PowerShell 5.1 / 7
- **Моделирование:** UML (PlantUML, Draw.io)
- **Базы данных:** SQLite, PostgreSQL
- **Версионный контроль:** Git, GitHub
- **Мониторинг:** WMI, CIM, Performance Counters
